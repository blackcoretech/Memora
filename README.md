# Memora

**Keep what matters.**

Memora is a proposed cloud-storage product designed to help people keep their important photos, videos, and files in one place and make more room on their devices.

> **Current stage:** Memora is in its early validation phase. The current project is a landing page, waitlist, and simulated product demo. Real cloud file storage, automatic backup, account-based file syncing, and payments are not yet available.

## Product vision

Memora aims to make storing and managing personal files simple and reassuring. The long-term vision is to let people store files in the cloud, access them when needed, and safely reclaim device space after confirming that their files have uploaded successfully.

Uploading a file to cloud storage does not automatically free space on a phone. A user must verify the cloud copy before choosing to remove the local copy.

## Current scope

The first release is limited to:

- A responsive product landing page.
- A waitlist registration experience.
- An interactive demo using fictional sample files and simulated actions.
- A clear explanation of the product vision and proposed plans.

The demo is illustrative only. It does not upload, store, back up, or retrieve real user files.

## Brand direction

- Primary colour: bright pink.
- Supporting colour: soft blush pink.
- Backgrounds: white and very light grey.
- Typography: clean, modern, and readable.
- Visual style: premium, minimal, mobile-first, with rounded cards and subtle shadows.

**Tagline:** Keep what matters.

## Roadmap

Potential future capabilities, subject to validation and development:

- Secure cloud file storage.
- Photo, video, audio, and document management.
- Reliable uploads, downloads, and file previews.
- Storage plans and subscription management.
- Account security, privacy controls, and data export.

These are roadmap goals, not currently available features. Security, privacy, retention, backup, and recovery systems must be designed and tested before real user files are accepted.

## Development principles

- Be transparent about what is live, simulated, and planned.
- Do not collect or store real user files during the validation phase.
- Keep waitlist data limited to what is necessary and protect it with appropriate database access controls.
- Validate demand and operating costs before building the full storage infrastructure.
- Build a polished, accessible experience that works well on mobile devices.

## Technology direction

The initial validation project is planned around:

- React with Vite for the web experience.
- Vercel for hosting.
- Supabase for waitlist data only.

The eventual storage and payment providers have not yet been selected.

## Project status

Memora is an early-stage product project. This repository will evolve as the landing page, waitlist, and simulated demo are built and tested.
